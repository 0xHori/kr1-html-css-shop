# Учебный frontend-проект: Интернет-магазин (ShopProject)

## Контрольная работа №1
Тема: «HTML и CSS: разработка многостраничного сайта».  
Дисциплина: «Фронтенд и бэкенд разработка».

## Описание
Многостраничный сайт интернет-магазина, разработанный на чистом HTML5 и CSS3 в соответствии с методологией БЭМ, современными практиками семантики, доступности и сеточных раскладок (Flexbox и CSS Grid). Проект служит технической базой для последующих контрольных работ.

## Структура сайта (обязательные страницы)
1. `index.html` — главная страница: hero-блок, преимущества, сетка популярных товаров с бейджами, диалоговое окно `<dialog>` быстрого заказа;
2. `catalog.html` — каталог товаров: двухколоночная Grid-раскладка с формой фильтров и карточками позиций;
3. `product.html` — страница карточки товара: детальная информация, оформление покупки и семантическая таблица спецификаций;
4. `order.html` — отдельная полнофункциональная страница оформления заказа с расширенной формой и памяткой покупателя;
5. `contacts.html` — страница контактов с реквизитами, режимом работы и ссылкой на форму заявки.

## Дополнительные файлы проекта
- `css/style.css` — модульный файл стилей с дизайн-токенами, БЭМ-классами и раскладками;

## Техническая реализация и архитектура

### 1. БЭМ-структура проекта
Все компоненты и элементы интерфейса приведены к соглашению БЭМ:
- `site-header` (`site-header__inner`, `site-header__logo`) — фиксированная шапка;
- `site-nav` (`site-nav__list`, `site-nav__item`, `site-nav__link`, `site-nav__link--active`) — основное меню;
- `breadcrumbs` (`breadcrumbs__link`, `breadcrumbs__current`) — навигационная цепочка;
- `product-card` (`product-card__title`, `product-card__description`, `product-card__price`, `product-card__badge`, `product-card--featured`, `product-card--discount`) — карточки;
- `product-table` — оформленная таблица характеристик;
- `order-form` (`order-form__field`, `order-form__label`, `order-form__input`, `order-form__select`, `order-form__textarea`, `order-form__actions`) — форма заказа;
- `order-dialog` (`order-dialog__title`) — модальное окно;
- `button` (`button--primary`, `button--secondary`) — переиспользуемые кнопки.

### 2. Сетки Flexbox и Grid
- **Flexbox**: горизонтальное меню сайта, внутренняя раскладка карточек товаров с прижатием кнопок к низу (`margin-top: auto`), кнопки управления формой, шапка;
- **CSS Grid**: сетка каталога товаров `products-grid` (3 колонки), структура страницы каталога `catalog-layout` (боковой сайдбар фильтров 260px + список товаров), раскладка страницы оформления заказа `order-layout` (2fr + 1fr).

### 3. Демонстрация позиционирования (CSS Positioning)
- `position: relative`: задан для контейнеров карточек товаров (`.product-card`) и медиа-блока товара;
- `position: absolute`: применён для бейджей статуса позиции (`.product-card__badge` — «Хит», «-15%», «New»);
- `position: sticky`: закрепление верхней панели шапки (`.site-header`) при прокрутке и сайдбара фильтров (`.catalog-filters`);
- `position: fixed` + `z-index`: плавающая кнопка «Наверх» (`.scroll-top-button`) в правом нижнем углу окна.

## Самостоятельные доработки (для повышенного уровня)
1. **Расширенная структура до 5 полноценных страниц** с уникальными мета-тегами (`title`, `description`, `Open Graph`) и взаимной перелинковкой.
2. **Семантическая таблица спецификаций** (`product.html`) с правильным использованием `<caption>`, `<thead>`, `<tbody>`, `<th>`, `<td>` и чередованием строк (`nth-child`).
3. **Реализация всех типов позиционирования** (`relative`, `absolute`, `sticky`, `fixed`, `z-index`).
4. **Система бейджей карточек товаров** с БЭМ-модификаторами статуса (`--featured`, `--discount`, `--new`).
5. **Двойной сценарий заказа**: быстрое оформление через модальное окно `<dialog>` с главной страницы и каталога + отдельная страница `order.html`.
6. **Высокий уровень доступности**: явный `:focus-visible`, подписи `label` для всех полей ввода, подсветка ошибок через `[aria-invalid="true"]`, плавная прокрутка.
